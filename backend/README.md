# Backend

See the [integrated project setup](../README.md) for environment configuration, local MongoDB, AI review/confirmation, and tests.

- API port: 4000
- MongoDB: replica set required for transactional sales/payments
- Start: `npm start`
- Local database: `npm run dev:local`
- Tests: `npm test`

Keep `.env`, `.cache/`, and `.local-data-mongo/` out of source control and download packages.
